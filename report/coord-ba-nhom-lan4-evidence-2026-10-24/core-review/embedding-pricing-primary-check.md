**Conclusion: a character-based undercharge is not established. Token-based pricing has direct Google Cloud support for this model's batch usage, but the exact online Vertex unit and its response-field billing mapping were not verified conclusively.** Do not promote a possible mismatch into a proven implementation defect, and do not sign off the online paid profile from the current generic “count” heading alone.

**Required before paid/profile sign-off (W15-R4-P1):** pin an authoritative online Vertex billing/SKU unit for `gemini-embedding-001:predict` and the metadata used to compute it; reconcile the reservation and receipt against that unit. Evidence and limits:

1. The current [Cloud pricing page, Embedding costs](https://cloud.google.com/gemini-enterprise-agent-platform/generative-ai/pricing#embedding-costs) publishes online 0.00015 USD and batch 0.00012 USD under a generic 1,000-count heading. It does not define that count as tokens or characters in this section. The legacy Vertex URL redirects here. Therefore this table alone cannot prove either unit.

2. The official [Google Cloud BigQuery embedding announcement](https://cloud.google.com/blog/products/data-analytics/use-gemini-and-open-source-text-embedding-models-in-bigquery), dated 2025-09-16, explicitly gives Gemini Text Embedding batch pricing in tokens and older text-embedding-005/multilingual-002 pricing in characters. It identifies the Gemini endpoint as gemini-embedding-001. This supports token billing for this model on Google Cloud, but is a batch example, not an explicit online SKU definition.

3. The [Vertex text-embeddings API reference](https://docs.cloud.google.com/gemini-enterprise-agent-platform/reference/models/text-embeddings-api) describes statistics.token_count as input text tokens, supports one text per gemini-embedding-001 request, and specifies a 2,048-token sequence limit. It also documents autoTruncate defaulting true. This validates the metric and model-window premises; it does not explicitly say that token_count is the online billing quantity. Its SDK example shows 13 tokens and 112 billable characters together.

4. Google's [official Python Gen AI SDK types](https://github.com/googleapis/python-genai/blob/main/google/genai/types.py) separately describe ContentEmbeddingStatistics.token_count and EmbedContentMetadata.billable_character_count for Vertex/Agent Platform. The latter is generic request metadata, without a model-specific online tariff guarantee. Its name is not enough to override the model's possible token pricing. The [Cloud get-embeddings guide](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/embeddings/get-text-embeddings) likewise presents both fields in the gemini-embedding-001 example.

5. The [Google Developers model announcement](https://developers.googleblog.com/en/gemini-embedding-available-gemini-api/) states 0.15 USD per million input tokens in its Gemini API pricing discussion. It mentions availability on Vertex, but this discussion does not independently settle the Vertex online SKU's unit. The [Cloud Gen AI SKU group](https://cloud.google.com/skus/sku-groups/gen-ai) lists Large Text Embedding Model - Predictions (`E4FB-7AE2-9CAE`) and its batch counterpart; the linked public SKU price view remained at a loading shell in this check, so neither its current unit nor a conclusive mapping to gemini-embedding-001 was established from that view.

Under the token interpretation, arithmetic is correct: 2,048 × 0.15 / 1,000,000 = 0.0003072 USD. Under a character interpretation, a token limit alone does not establish the same character bound; a response with both token and character counts can produce different costs. That is a conditional risk, not evidence that Google billed this run by characters. No real run or invoice was used to resolve it.

The synthetic fake-provider probes and receipts in the earlier review remain valid only for their supplied token-price fixture. They cannot establish Google's billing contract. Overall full-package verdict remains request changes for the reproduced Windows defect, plus this separate paid-profile evidence prerequisite; full W15 remains open.
