## Approved change and tests

The measured V3 sample “Tập hợp” had the concept name in the stem, while the correct option was a description of the primitive concept. Before the change, `local.target_name_in_stem` rejected it. The Codex coordinator recorded the narrow implementation decision under the owner's delegation: reject when a concept name or alias appears in the stem **and** the correct option is itself exactly that name or alias. Thus the sampled candidate reaches the verifier but is still rejected because its distractors are not distinguished by evidence. Claude's independent policy review remains pending.

Focused regression tests cover both sides: a descriptive correct answer with the target named in the stem passes this local rule, while using the target name as the correct answer remains rejected. A captured fake-model M10 test runs generation and blind verification with a deliberately wrong selected option but complete “sai theo nguồn” distractor verdicts; it confirms the candidate is rejected with exactly `verifier.wrong_choice`. No verifier records are fabricated during replay.

The focused quiz and assistant-content suites (`test_phase_b_quiz.py`, `test_phase_b_quiz_sa27.py`, and `test_phase_b_assistant_content.py`): **31 passed**. The run also emitted a Windows permission warning for pytest's cache directory; it did not affect the test result.
